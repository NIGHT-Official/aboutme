Method

How I work

The same five habits on every project.

1

Design before code

A written design with numbered requirements, and a rough sketch of the screen agreed before anything is built. Nothing had to be rearranged afterwards.

2

Small steps, each one checked

Work is cut into milestones with an exit test. Each is built, tested on Windows and Linux automatically, and reviewed before the next begins.

3

Check the research

AI research is treated as a claim, not a fact. A second pass found 7 errors in 33 researched items in one design before any code depended on them.

4

Test the real thing

Stand-ins are not enough. The first real call to a deployed server failed twice in ways no test had shown, in a sandbox, before any customer existed.

5

Write down what went wrong

Every project keeps a dated log and a case study, including the mistakes: mine, the tools', and the research's. You get the same record for your project.

What I can build for you.
